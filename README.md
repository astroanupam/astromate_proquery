# ASTROMATE - 100 QUERY MASTER

Ask Your Question. Understand the Planetary Indications. Explore the Likely Outcome.

A question-based Vedic (Parashari, Lahiri, whole-sign) astrology app for daily professional activities: enter your birth details once, pick one of 100 professional questions, and get a YES / NO / MAYBE indication from your natal chart and the transits of the day (special weight on the transit Moon), with a complete explanation.

* Installable on Android, iPhone and desktop; works offline.
* Everything is calculated on the device. Birth data is stored encrypted on the device and never sent anywhere.
* Three interfaces: user app, astrologer / researcher dashboard, administrator dashboard (the first account created is the administrator).
* Open `tests.html` to run the 162 automated checks (time zones, Ascendant, planetary positions against NASA/JPL Horizons, house ownership for all 12 Lagnas, dignity, aspects, Moon transits, the 100 rule sheets, the decision logic, reproducibility, mobile layout, data security).

Astrology is a traditional interpretive system. Results are indications, not guarantees, and not medical, legal or financial advice.

See `THIRD-PARTY-NOTICES.txt` for data sources. Full documentation (architecture, rules, security, testing, database schema, server edition) is in the `docs` folder of the complete project. This static package is the browser edition (`config.js` says `mode: 'local'`); the project also contains a server edition with shared logins and a central database.
